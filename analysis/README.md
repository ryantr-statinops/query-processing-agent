# Exploratory analysis

This directory holds one-off Python investigations used while reviewing the
competition questions and source files. The numbered scripts inspect question
patterns, intent and time wording, inventory formats, spreadsheet headers and cell
formats, SQLite schemas, product names and status values.

These scripts are exploratory utilities, not runtime modules or a supported test
suite. Some read local `train/` data and a few write summary JSON files into this
directory. Generated JSON and markdown summaries remain ignored; keep source data,
labels and derived row-level artifacts out of commits.
